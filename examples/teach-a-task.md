# Teach-a-Task：把一次手动操作录成技能

> 你先完整做一遍给 bot 看（或留下可复核的步骤记录），再收成可复用 skill / 清单，下次同类型任务少问你。

- **适合**：重复出现的本机或浏览器流程（整理目录、填表、发布前检查、固定格式周报等），想沉淀成团队可抄技能
- **验证日期**：2026-10-18（**待真机验证**；本文为脱敏虚构配方草稿，任务名与样例均为假）
- **验证级别**：待验证
- **成本量级**：免费～低

## 场景

同一类操作你教了 bot 三遍，下次它仍漏步骤或发明新路径。Teach-a-Task 的核心是：**一次示范 → 结构化技能卡 → 小样本复跑 → 人签收**。技能卡里只写可公开的步骤与 `{{占位符}}`，不写真实路径、账号、密钥。

Grok Bot 自带 Teach a Task：据公开介绍，在 bot 的云电脑上演示一遍，它就能存成可复用的技能。本配方不替代这个功能，补的是它前后两头：演示前想清楚边界和成功标准，演示后把技能整理成可审、可脱敏、可分享的卡片，并先干跑再放手。

## 输入

- 一次完整示范：屏幕录制文字稿 / 逐步笔记 / 聊天里的「我来做一遍」记录
- 任务边界：`{{任务名称}}`、触发条件、成功标准、明确不做的事
- 环境类型：本机文件 / 浏览器 / 仓库 git / 第三方网页（只写类型）
- 可变项清单：每次会变的名字、日期、目标目录等 → 全部变成 `{{占位符}}`

## 步骤

1. **示范**：人完整做一遍；bot 只观察或读取你提供的步骤记录，中途不抢着执行
2. **抽取技能卡**：bot 输出目标、前置条件、步骤、校验、回滚/失败怎么说；标出所有可变项为占位符
3. **人改一版**：删掉内部绝对路径、真实域名、账号；补上「禁止事项」
4. **干跑**：用虚构输入走一遍，只生成计划不落真实副作用；人对齐预期
5. **小样本真跑**（可选）：人选一个低风险实例让 bot 执行；失败则回写技能卡，而不是口头再教一次
6. **入库**：脱敏后的技能卡放进 `examples/` 或私有 skills 目录；公开仓只收通用版
7. **调用约定**：以后同任务先读技能卡再执行；技能卡与对话冲突时以技能卡 + 人当场指示为准

## Prompt

从示范生成技能卡：

```text
你是技能整理员。根据以下「一次完整示范」记录，生成可复用技能卡。

任务名称：{{任务名称}}

示范记录：
{{示范步骤或文字稿}}

输出结构（Markdown）：
# {{任务名称}}
## 目标（一句话）
## 前置条件
## 输入占位符（表格：名 / 含义 / 示例假值）
## 步骤（编号，每步可验证）
## 成功标准
## 失败与回滚
## 禁止事项（必须包含：不写 key；不对外发送；不删未确认文件）

规则：
- 真实绝对路径、邮箱、密钥改成 {{占位符}}
- 不要发明示范里没出现的点击或命令
- 有副作用的步骤标 [需人工确认]
- 若示范含糊，列出「待澄清」而不是猜测
```

按技能卡执行（第二次及以后）：

```text
按技能卡 {{技能卡路径或粘贴}} 执行任务。
本次变量：
{{占位符赋值表}}

先输出「计划」：将执行的步骤摘要 + 副作用列表。
等待人回复「确认」后再执行；未确认只准干跑。
执行中每步写简短日志；偏离技能卡时停止并询问。
```

## 产出

虚构示例（整理「发布前检查」技能，产品为假）：

```text
# 发布前检查 · AcmeTools 文档站
## 目标
在宣布更新前，确认公开文档链接可打开且无占位符残留。

## 输入占位符
| 名 | 含义 | 示例假值 |
| {{文档根URL}} | 公开文档站点 | https://docs.example.com |
| {{版本号}} | 本次版本标签 | v0.0.0-demo |

## 步骤
1. 打开 {{文档根URL}}/changelog 确认 {{版本号}} 条目存在
2. 抽查 3 个内链可打开
3. 全文搜索 TODO / FIXME / {{ 是否残留
4. 输出检查表给人对勾；[需人工确认] 后方可宣布

## 禁止事项
不修改生产配置；不发送公告；不提交 git push
```

## 坑

- **示范含糊却急着自动化**：步骤里「随便点点」无法复现；示范时边做边说目标与成功标准
- **把内部路径写进公开技能**：绝对路径、真实仓库名、员工目录会泄漏；公开版只留类型与占位符
- **技能卡与对话打架**：临时口头指示会覆盖卡片却不回写，下次又错；改了流程就更新卡片
- **一次教会、永不校验**：产品 UI 一变技能即失效；标「验证日期」，超过 90 天未复查加 ⚠️
- **跳过干跑直接真跑**：有副作用（发信、删文件、push）必须先计划 + 人确认；本配方默认干跑优先
- **和作战室角色混淆**：Teach-a-Task 沉淀的是「单人可复用步骤」；多 bot 分工与文件交接见 `war-room.md`
