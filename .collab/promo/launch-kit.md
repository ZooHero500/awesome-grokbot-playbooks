## 0. 第一次推 GitHub 项目，先知道这几件事

1. **star 要集中在同一天来**。GitHub Trending 看的是短时间内的新增 star，同样 100 个 star，一天内来比一周慢慢来更容易上榜。所以各渠道尽量在今晚到明天中午之间发完。
2. **链接直接给仓库地址**，不要只说「搜一下」。每条文案都带 `github.com/sit-in/awesome-grokbot-playbooks`。
3. **明确请人点 star**。国内很多人不知道 star 是什么，要说一句「右上角点 ⭐，帮它上榜」。
4. **作者转发最有效**。被收录项目的作者有动力转，因为也在帮他们自己宣传。用第 8 节的私信模板。
5. **头 48 小时回复要快**。issue、评论、私信尽量当天回，第一批人的体验决定他们会不会再转。
6. **别做**：买 star、互刷 star、群发陌生人、在不相关的群刷屏。GitHub 会清理刷的 star，社区也会反感。
7. **把仓库挂出来**：X 简介、GitHub 个人主页（Pin 这个仓库）、公众号菜单都放上链接，这些位置长期带量。

## 9. 评论区常见问题怎么回

**AI 维护的清单靠谱吗？**
> 每一条都用 GitHub API 和接口核实过：存在、有许可、还在更新。收录规则公开在 CONTRIBUTING 里。配方分三级标记，✅ 只给真机跑通的。AI 负责干活，规则和最后的决定是人定的。

**和英文的 awesome-grok-bot 有什么区别？**
> 那个是导航，覆盖面广。我们侧重中文、一人公司场景和能直接抄的配方，两边互补。

**怎么参与？**
> 三种方式：推荐项目开 issue；按 `examples/_template.md` 投配方；去 Issues 认领一个「实测认领」，跑通署名。

**Grok Bot 怎么开通 / 多少钱？**
> 以 x.ai/bot 官方页面为准，我们不代理、不卖号。
